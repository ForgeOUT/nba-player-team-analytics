# NBA Player & Team Performance Analytics

## Project Overview

This project analyzes NBA player and team performance using Python, pandas, Matplotlib, SQL, and SQLite.

The project combines Python-based exploratory data analysis with SQL analysis to examine player production, team performance, efficiency metrics, positional trends, and player contributions within their teams.

The goal of this project is to use a real sports dataset to demonstrate practical data-analysis and SQL skills while answering meaningful basketball-related questions.

## Tools & Technologies

- Python
- pandas
- Matplotlib
- SQL
- SQLite

## Dataset

The analysis uses NBA regular-season player data for the 2025–26 season.

The dataset includes information such as:

- Player
- Team
- Position
- Assists
- Rebounds
- Minutes played
- Wins
- Losses

The Python analysis uses pandas to inspect, transform, analyze, and visualize the data. The same data is also used for SQL analysis through SQLite.

## Python & pandas Analysis

The Python portion of the project includes:

- Inspecting the dataset structure and descriptive statistics
- Checking for missing values and duplicate rows
- Examining data types
- Ranking players by assists
- Calculating assists per game
- Calculating rebounds per game
- Comparing average assists by position
- Comparing average assists per game by team
- Comparing rebounds and assists by position
- Identifying top rebounders
- Identifying top assist producers
- Creating visualizations of assists and rebounds by position

## SQL & SQLite Analysis

The SQL portion of the project uses multiple analytical queries to examine NBA player and team performance.

The queries use:

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- Aggregate functions
- Calculated fields
- Subqueries
- Window functions
- PARTITION BY
- ROW_NUMBER()

The SQL analysis examines topics such as player assists, assists per minute, team performance, team assist production, player contributions to team assists, and other efficiency metrics.

## Key Findings

Some notable findings from the analysis include:

- Nikola Jokić ranked first in several assist-based analyses.
- San Antonio had the highest team win percentage in the analysis at 75.61%.
- Nikola Jokić accounted for approximately 27.27% of Denver's team assists in the team-assist-share analysis.
- The analysis identified the leading assist producer for each team.
- The Python analysis showed differences in assist and rebound production across player positions.
